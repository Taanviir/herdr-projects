# Projects has moved

Projects now lives in [Taanviir/my-herdr-plugins](https://github.com/Taanviir/my-herdr-plugins/tree/main/projects),
with the other Herdr plugins. This repo is archived.

To switch an existing install:

```bash
herdr plugin uninstall taanviir.projects
herdr plugin install Taanviir/my-herdr-plugins/projects
```

Your settings, key bindings and saved state stay where they are.
